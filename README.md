# AdminSeguro CTG

Prototipo web para gestionar reservas, clientes, servicios turísticos, inventario y usuarios de **International Group** (Cartagena de Indias).

**Materia:** Aplicaciones Web · Corporación Universitaria Rafael Núñez
**Integrantes:** Paulo Bárcenas Yaneres, Isabel Sofia Pérez Villafañe, Leonardo Ramírez Franco, Javier José Torres Castillo
**Docente:** Maybelline Castro Pérez

## Tecnologías
HTML, CSS y JavaScript (frontend). Node.js y MySQL se integran en la cuarta entrega.

## Cómo ejecutarlo
Abrir `index.html` en el navegador (o con la extensión Live Server de VS Code).

| --- | --- | --- |
| Administrador | admin | Admin123 |
